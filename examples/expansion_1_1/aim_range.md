# Aim Range
Build an offline aiming game on a 400x240 canvas. A stationary target circle is centered at (300,80), radius 22. Clicking the canvas sets an aim point. #fire launches one projectile from (40,200) directly toward the aim point at 300 pixels/second, without gravity. Only one projectile can be active; repeated fire while active does nothing. Every launched projectile increments shots. A real collision with the target adds one score and wins; a missed projectile exits the canvas, deactivates and allows another shot. Stop/ignore gameplay after winning. #restart clears score/shots, deactivates the projectile and returns Playing. Draw aim indication and projectile; show English instructions.
Use #score, #shots (bare integers). Read-only window.__gameTest.getState() returns real score, shots, shotActive and phase (Playing/Won). Vanilla local HTML/CSS/JS only.
