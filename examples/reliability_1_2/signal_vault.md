# Signal Vault
Build a small offline vanilla HTML/CSS/JavaScript game in English. Use a visible [data-game-surface] area, native select #mode (values color and code), text input #answer, buttons #submit, #charge and #restart. Show bare integer counters #energy and #attempts, and #phase containing exactly Playing or Won.
Initial mode is color, energy 3, attempts 0, answer empty and phase Playing. Display public clues: color requires exactly BLUE; code requires exactly 42. Matching is case-sensitive with no trimming.
While Playing, submitting empty text or submitting with energy 0 is a no-op. Every accepted non-empty submission costs one energy and adds one attempt, including a correct answer. An exact match for the current mode changes phase to Won; an incorrect answer leaves Playing. Charge adds two energy capped at 4, without consuming an attempt. Changing mode while Playing clears the answer but preserves energy and attempts. After Won, submit, charge and mode changes do nothing. Restart always restores all initial values and color mode.
Expose a read-only window.__gameTest.getState() snapshot with actual energy, attempts and phase. Do not add timers, external assets, storage, a backend or extra game rules.
